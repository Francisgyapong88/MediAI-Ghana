CREATE A COMPLETELY NEW, PROFESSIONAL, HIGH-END WEB APPLICATION DESIGN FOR:

MEDiAI GHANA

Subtitle:
“Non-Diagnostic Clinical Decision-Support Prototype”

IMPORTANT:
This is NOT a generic healthcare website.

Design the interface specifically from the requirements, scope, architecture, safety boundaries, roles, workflow, and technical evaluation framework described below.

The application is an undergraduate proof-of-concept called MediAI Ghana. It demonstrates a web-based clinical decision-support workflow using synthetic symptom records and a restricted four-condition machine-learning classifier.

The design must look like a serious professional health-tech / clinical software platform suitable for a university final-year project demonstration.

It must NOT look like:
- A hospital management system
- A patient portal
- A medical booking platform
- A consumer symptom checker
- An autonomous AI doctor
- A generic AI chatbot
- A pharmaceutical website

It should look like:
- A secure clinical decision-support research platform
- A professional health-tech SaaS application
- A technical AI evaluation platform
- A controlled clinical software prototype
- A Ghana-focused academic technology project
